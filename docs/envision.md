# Envision is not used

This repo is **standalone**. `install.sh` / `build.sh` compile Monado + xrizer
into `~/.local/opt/vive-monado`. `launch-monado.sh` starts `monado-service`
directly.

Do not install Envision for this stack. Do not start it. If an old AppImage
is still on disk from an earlier revision, ignore it.

See [build.md](build.md).
